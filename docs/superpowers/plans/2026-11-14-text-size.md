# Text size preference implementation plan

**Goal:** Let people choose a smaller or larger font size throughout the unified app and retain it on this device.

**Design:** Small (90%), Standard (100%, default), Large (115%), Extra large (130%).
The preference multiplies the operating system's text scaler without flattening
nonlinear accessibility scaling. Remove only the unified app's forced 115% floor.
Use the existing fonts, themes, target sizes, and local preference store. Show the
same localized setting in Welcome, Family More/patient Help, and Companion Me.
Selection applies immediately and survives app restart and sign-out. This is a
device preference, not patient/account data. No auth, RPC, database, or provider change.

**Architecture:** Unified app owns the preference and its inherited settings
scope. Existing Family/Companion/Welcome screens accept an optional control widget;
standalone apps and their existing scaling remain compatible. SharedPreferencesAsync
loads/saves the enum's stored name using the existing startup preference pattern.

**Tech stack:** Flutter, existing shared_preferences, EN/TE/HI ARBs.

## Files

- Unified `lib/src/text_size.dart`: presets, scaler, scope, setting control.
- Unified `lib/src/app.dart`, `lib/main.dart`: state, scaling, persistence wiring.
- Unified Welcome/Companion home and Family home: optional settings slot.
- Unified three ARBs and focused tests; required tracking/evidence documents.
