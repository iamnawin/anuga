# Task template

Task ID/title; owner or Unassigned; status; branch/worktree/base SHA; PR or none.
User outcome; linked screen/feature IDs and approved contract/spec.

Owned write paths (exact); read-only dependencies; explicit excluded scope;
shared contract owner and conflicts. Reserve in WORK_BOARD before starting.

Acceptance scenarios; inspect → one focused action → verify loop; pass limit;
stop on success/no progress/blocker/risk; approval boundary and checks to run.

Finish receipt: changed files/behavior, reused code, API/permission deviations,
exact check commands/results/skips, synthetic UI screenshots if relevant,
base/result SHA, PR if authorized, remaining decisions and next integration step.
Coordinator updates shared docs; contributor edits only this task and owned spec.
